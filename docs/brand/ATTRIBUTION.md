## Derived files

The SideSpeed logo and icons are a modified version of the Android robot. The
master is `docs/brand/sidespeed-logo-2026.png`; everything below is generated
from it by `docs/brand/make-icons.py`:

- `app/src/main/res/mipmap-mdpi|hdpi|xhdpi|xxhdpi|xxxhdpi/ic_launcher.png` and
  `ic_launcher_foreground.png` (TV app launcher, adaptive + legacy)
- `app/src/main/res/drawable-xhdpi/banner.png` (Android TV / Fire TV banner)
- `companion-android/src/main/res/mipmap-mdpi|hdpi|xhdpi|xxhdpi|xxxhdpi/ic_launcher.png`
  and `ic_launcher_foreground.png` (companion launcher, adaptive + legacy)
- `companion-desktop/src/main/resources/icons/app.png`, `app.icns`, `app.ico`
  (desktop app icon)
- `companion-desktop/src/main/resources/tray.png` (desktop tray icon)
- `companion/src/desktopMain/resources/ss_logo_mark.png` (companion header mark on desktop)
- `companion/src/androidMain/kotlin/.../ui/SsLogoMarkBytes.kt` (same mark as
  embedded bytes for the companion header on Android)
